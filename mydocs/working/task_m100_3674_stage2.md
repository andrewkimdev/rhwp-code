## 작업지시자 확인 요청 — 표 객체의 문단 배치 속성 소비 (2026-08-04 3보)

Q&A 표 호스트 문단의 [PS]: **`line=160/Percent`, spacing before=0 after=0**,
표 common: `treat_as_char=true, wrap=자리차지, vert/horz=문단(0mm)`.

가설 검증 상태 — "TAC 표 줄에 160% 줄간격이 곱해져 유령 공간이 생긴다":

| 사례 | 수치 | 가설 부합 |
|---|---|---|
| p293 밀림 | 210×1.6=336 > 잔여 258.8 | ✓ |
| p296 밀림 | 304.7×1.6=487 > 잔여 405.8 | ✓ |
| p299 밀림 | 280.2×1.6=448 < 잔여 512 | ✗ (선행 TextLine 동반 이동 의심) |

**해석(잠정)**: 줄간격 160% 가 쪽 "채움 판정(fit)"에는 개입하고 실제 "배치 전진"에는
빠지는 이중 계산 가능성 — #359 의 fit/누적 분리 결함과 같은 형태. 다음 세션에서
경계별로 rhwp 의 fit 요구량을 직접 재현해 확정한다(각 쪽나눔 지점의 needed vs slack).

행 분할 축(RowBreak 무시)과 이 축은 독립 — 분할이 되면 fit 과대평가와 무관하게
잔여가 채워진다. 두 축 모두 수정 후보.
