축 B(+9)의 본질은 **표 셀/행 높이 계산의 한컴 대비 팽창**이다. Q1 쪽(재저장본 p285)
실측: rhwp 는 Q1 블록 표를 **289.6px**, Q2 를 **231.3px** 로 계산 — 한컴은 같은 쪽에
질문 3개를 넣는 밀도다.

## 도구 확인 — 하니스 재료가 이미 있다

| 쪽 | 명령 | 제공 |
|---|---|---|
| 저장 진실 | `dump` | 문단별 LINE_SEG(vpos·lh·ls), PS(line=180/Percent 등), 셀 지오메트리(h·pad·valign) |
| rhwp 계산 | `export-render-tree` | 쪽별 Table/TextLine bbox + pi |

하니스 = 이 둘의 조인. 문단은 pi, 표는 순서·위치로 대응시킨다.
