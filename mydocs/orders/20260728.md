## Issue #3481 — HWP3 비밀번호 암호 문서 복호화

[#3481](https://github.com/edwardkim/rhwp/issues/3481)을 [PR #3483](https://github.com/edwardkim/rhwp/pull/3483)에서
처리한다.

- 압축 HWP3 비밀번호 문서의 DES 복호화, raw DEFLATE CRC32/ISIZE 검증, 512 MiB 압축 해제 상한을
  `src/parser/hwp3/`에 구현했다. 잘못된 비밀번호와 손상 입력은 같은 일반 오류로 처리하며, 비압축
  HWP3 암호 payload는 명시적으로 거부한다.
- 공용 parser·CLI·WASM·Studio의 기존 암호 입력 경로로 HWP3를 열 수 있게 했고, 실제 fixture로
  미입력·오입력·성공·CLI stdin·평문 저장 재열기를 고정했다. Studio는 HWP3/HWP5 모두에 취소·오입력·Enter
  성공·storage 비보존 브라우저 E2E를 실행한다.
- 새 fixture의 IR field sweep은 803개 샘플에서 baseline TSV와 차이가 없었다. Rust 전체 release-test,
  fmt·clippy, WASM build, Studio 674개 node test·production build, Chrome·Firefox 확장 build를 통과했다.
- 실제 Studio에서 HWP3 문서를 열어 24쪽·1쪽 canvas 화면을 확인한 증적은
  `mydocs/pr/assets/pr_3483_hwp3_password_open_review.png`에 보존했다. renderer fidelity 변경을
  주장하지 않으므로 Hancom 기준 PDF 대조·visual sweep은 수행하지 않는다.
- 이전 형식 표기는 `HWP3`로 통일했다. 원본 문서 본문의 "한글 97" 표기는 포맷 용어가 아니므로
  변경하지 않는다.
