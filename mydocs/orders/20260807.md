## #4080 - 캐시 스윕이 `main` 정의로 돌아 고아 정리가 발동하지 않았다

- [PR #4082](https://github.com/edwardkim/rhwp/pull/4082) merge 뒤 첫 정기 스윕
  ([run 31134261783](https://github.com/edwardkim/rhwp/actions/runs/31134261783))이 삭제 0건으로 끝났다.
  로그가 `GiB` 가 아닌 `GB` 표기였고 고아 정리 줄이 없어 확인하니 `head_branch=main` 이었다.
- `schedule` 이벤트는 기본 브랜치 정의로만 실행된다. `devel` 은 `main` 보다 1,110커밋 앞서 있어
  #4082 의 변경이 정기 스윕에 반영되지 않는다. 같은 함정이 #3508 에서 실측되고 #3812 제목에도
  적혀 있었는데 #4082 작업에서 확인 항목으로 두지 못했다.
- 응급 조치로 `workflow_dispatch --ref devel` 를 실행해 병합된 로직을 돌렸다
  ([run 31137319200](https://github.com/edwardkim/rhwp/actions/runs/31137319200)). 고아 23건 2.50GiB 를
  삭제하고 **51개 9.07GiB → 28개 6.57GiB**, 십진 한도 대비 97.4% → 65.7% 로 내려갔다. 삭제 실패 0건,
  열린 PR 13건의 캐시는 모두 보존됐다. 문서에 남긴 관찰 기준치 6.57GiB 와 정확히 일치했다.
- `main` 반영은 메인테이너가 직접 처리하기로 했다. 우리 쪽 작업 없음.
- `devel` KEEP=1 재검토 근거로 캐시 접근 시각 분석을 이슈에 남겼다 — 다세대 쌍 8개 전수에서
  "신세대 생성 이후 구세대 접근" 0건이며, restore-keys 프리픽스 매칭이 항상 최신을 고르는 설계의
  귀결이다. 추가 절감 여지는 1.99GiB 이나 고아 정리 실측이 안정된 뒤로 미룬다.

## #4040 - 파일 게이트된 native-skia test 3건이 CI 에서 실행되지 않았다

- 이슈는 `issue_2293_chart_png_text.rs` 한 건만 지목했으나, 저장소를 훑어 확인하니
  `issue_2083_hide_fill_page_background.rs`·`issue_2292_chart_png_clip.rs` 도 같은 상태였다. 회귀 가드
  3건이 죽어 있었다. 이슈 본문을 3건 범위로 갱신하고 발견 경위를 코멘트로 남겼다.
- 결함이 셋이었다. ① Native Skia job 이 세 target 을 실행하지 않음 ② classifier 가 이 파일들을
  native-skia 소유로 보지 않아 `native_skia_required=false` 판정 — job 배선만 고치면 정작 그 파일을
  고치는 PR 에서 job 이 skip 된다 ③ 기존 계약 테스트가 job 이 실행하는 target 만 순회해 **양쪽 어디에도
  없는 파일**을 못 잡았다.
- workflow 에 `--test` 3개를 release-test·release 두 경로에 추가하고, classifier 소유 목록에 세 경로를
  더했다. 계약 테스트는 저장소를 훑어 부류 자체를 강제하도록 3건 추가했고 기존 단방향 테스트는
  역방향 감시용으로 남겼다.
- 발견 패턴은 중첩 게이트를 처리해야 한다 — `render_p37_direct_pdf_export` 가
  `#![cfg(all(not(target_arch = "wasm32"), feature = "native-skia"))]` 형태다. RED 재현에서 드러나
  판별식을 고쳤다.
- 로컬에서 세 테스트를 `native-skia` 로 직접 실행해 모두 통과했다(각 1 passed). 죽은 테스트를 되살린
  것이 아니라 유효한 검증이 CI 에서 빠져 있던 것이다.
- 계약 테스트 57건, node classifier 28건, `actionlint`, `node --check`, `git diff --check` 통과.
  뮤테이션 4종이 각각 해당 테스트를 실패시키는 것을 확인했다.
- PR 생성과 원격 CI 의 Native Skia job 로그 확인, 소요시간 증가폭 실측이 남았다.
